# Car Hunter

A lightweight installable PWA for tracking New Zealand car listings.

## Current features
- Add listing details and Trade Me URL
- Track price, kilometres, year and transmission
- Shortlist and remove cars
- Local browser storage
- Installable app shell and basic offline caching

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, then **Save**.
5. Wait for deployment and open the URL shown in the Pages panel.

## Important
This starter does not connect to Trade Me or Gmail. Listing alerts remain the discovery source until an authorised email-processing workflow is separately configured. Entries are currently stored in the browser on each device and do not sync between devices.
